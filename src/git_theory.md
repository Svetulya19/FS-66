# Теория Git

## Что такое Git

Git — это система контроля версий. Она позволяет сохранять историю изменений проекта и возвращаться к предыдущим версиям.

## Основные понятия

### Repository
Репозиторий — папка проекта, историю которой отслеживает Git.

### Commit
Commit — сохранённая точка состояния проекта.

### Branch
Branch — отдельная ветка разработки.

### Remote repository
Удалённый репозиторий — копия проекта на сервере, например GitHub.

## Основные команды

```bash
git init
```
Создать Git-репозиторий в текущей папке.

```bash
git status
```
Показать состояние файлов.

```bash
git add .
```
Добавить изменения в staging area.

```bash
git commit -m "message"
```
Создать commit.

```bash
git log
```
Посмотреть историю commit'ов.

```bash
git branch
```
Посмотреть ветки.

```bash
git switch -c new-branch
```
Создать новую ветку и перейти на неё.

```bash
git remote -v
```
Посмотреть подключённые удалённые репозитории.

```bash
git push
```
Отправить commits в удалённый репозиторий.

```bash
git pull
```
Получить изменения из удалённого репозитория.

## Git и GitHub — не одно и то же

- **Git** — программа для контроля версий.
- **GitHub** — интернет-сервис для хранения Git-репозиториев.

## Простейший рабочий цикл

1. Изменить файл.
2. Выполнить `git status`.
3. Выполнить `git add .`.
4. Выполнить `git commit -m "описание изменений"`.
5. При необходимости выполнить `git push`.
